# Sapphire Internship - Week 1 Assignment

This project represents the completion of Week 1 objectives for the Full Stack Internship program, transitioning from static web fundamentals to a modern React architecture.

## Tech Stack & Features
- **Frontend Architecture**: React 18 with Vite
- **Styling**: Custom CSS (Deep Slate & Electric Indigo design system) with CSS Grid & Flexbox
- **React Hooks**: Managed state using `useState` and handled data fetching using `useEffect`
- **Version Control**: Git & GitHub repository integration

## Project Structure
- `client/` - Modern React application
- `client/week-01/` - Legacy HTML/CSS/JS files preserved for review

# Sapphire Internship - Week 2 Assignment

This project represents the completion of Week 2 objectives for the Full Stack Internship program, focusing on advanced React concepts, routing, API integration, and global state management.

## Tech Stack & Features

* **Routing**: Multi-page Single Page Application (SPA) built using React Router v6 with dynamic navigation.
* **API Integration**: Consumed live REST APIs via Axios with robust loading and error handling states.
* **State Management**: Managed shared global state using React Context API for features like theme toggling.
* **Version Control**: Git & GitHub repository integration

## Project Structure

* `client/` - Modern React application with multi-page components and API integration

# Sapphire Internship - Week 3 Assignment

This project represents the completion of Week 3 objectives for the Full Stack Internship program, building a complete backend stack and secure REST API with database integration.

## Tech Stack & Features

* **Backend Environment**: Node.js and Express framework with modular MVC structure.
* **Database & ORM**: PostgreSQL database integrated using Sequelize ORM for schema definition and CRUD operations.
* **Security & Auth**: Secure User Registration and Login endpoints protected via JSON Web Tokens (JWT) and bcrypt hashing.
* **API Testing**: Fully tested REST endpoints verified via Postman collection.

## Project Structure

* `server/` - Backend Node.js, Express & Sequelize application with authentication and routes
